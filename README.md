# Parcer-for-ETS2

Консольная утилита на Node.js, которая собирает список украинских
интернет-радиостанций с [onlineradiobox.com](https://onlineradiobox.com/ua/)
и генерирует файл `live_streams.sii` с рабочими потоками для внутриигрового
радио в **Euro Truck Simulator 2**.

## Что делает

1. **Скрапит** каталог радиостанций с `onlineradiobox.com/ua/` (14 страниц),
   загружая их параллельно с ограничением одновременных запросов.
2. Для каждой станции извлекает **URL потока, название и жанр**.
3. **Проверяет работоспособность** каждого потока: делает HTTP-запрос,
   следует за редиректами (с защитой от их зацикливания), отсеивает заранее
   известные нерабочие потоки и пропускает неподдерживаемые форматы
   (AAC, OGG, HLS/m3u8).
4. **Определяет битрейт** — из URL/названия станции, а при отсутствии данных
   замеряет его по первым ~64 КБ потока.
5. **Формирует файл** `live_streams.sii` в формате ETS2, готовый к
   подключению в игре.

## Требования

- Node.js (проект использует ES-модули, глобальный `fetch` и протокол `node:`;
  рекомендуется Node.js 18+).
- Доступ в интернет (утилита выполняет живой сетевой скрапинг).

## Установка

```bash
cd NodejsConsoleApp2
npm install
```

## Запуск

```bash
node app.js
```

По завершении в текущей папке будет создан файл `live_streams.sii`. В консоль
выводится прогресс: подключение к сервису, загрузка страниц, число найденных
рабочих станций и подтверждение создания файла.

### Формат строки в `live_streams.sii`

```
stream_data[N]: "<URL потока>|<название>|<жанр>|UA|<битрейт>|0"
```

## Структура проекта

| Файл                   | Назначение                                                        |
| ---------------------- | ----------------------------------------------------------------- |
| `app.js`               | Точка входа: скрапинг, парсинг станций и генерация `.sii`-файла    |
| `streamValidation.js`  | Проверка работоспособности потоков и определение битрейта          |
| `brokenStreams.js`     | Список известных нерабочих потоков и функция их отсева             |
| `constants.js`         | Общие константы и HTTP-заголовки                                   |
